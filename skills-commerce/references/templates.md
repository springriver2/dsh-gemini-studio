# 镜头模板

按段落给模板，`{}` 里换成实际内容。**一镜一句台词**，句子 ≤ 9 秒。

## S01 钩子

> 画面：{主播} 对着镜头，{动作：抬起手腕/拿起杯子/把商品放桌上}，半身近景，{场景}，{光}。
> 运镜：固定机位，轻微推近。
> 台词：{一句反常识或痛点提问，不出现商品名}

可用钩子句型：

- "你是不是也 {某个常见做法}，结果 {反效果}？"
- "别急着买，先看这个。"
- "同一件东西，为什么有人戴三天就扔？"
- "{数字} 块钱和 {数字} 块钱的差别，全在这。"
- "我不推荐你买它，除非你先看完这一段。"

## S02 引出商品

> 画面：{商品} 完整入画，{主播} 用手托起并缓慢转动，让 {关键面} 正对镜头；{场景}，{光}。
> 运镜：手部动作带动，镜头跟随轻微右移。
> 台词：{品类 + 一个可验证的差异}

写差异时只写能看见的：材质、工艺、颗数、尺寸、产地、颜色来源。不写"高档""顶级"。

## S03 近景 / 细节

> 画面：微距特写，{商品} 占画面 50%，光从 {方向} 扫过 {表面/纹理/切面}，能看清 {细节特征}。
> 运镜：极缓横移或固定。
> 台词：{一句质感描述 + 一个细节}

品类替换：

| 品类 | 细节镜头拍什么 |
| --- | --- |
| 手串 / 首饰 | 孔道、颗粒包浆、金属扣、光下的透感 |
| 服饰 | 走线、面料垂坠、拉链/纽扣、翻面内衬 |
| 家居 | 边角处理、材质纹理、与手的比例 |
| 食品 | 切开断面、拉丝、热气、入口咀嚼 |
| 美妆 | 质地推开、上脸前后同一光位对比 |

## S04 上身 / 使用

> 画面：{商品} 戴在 {手腕/手指/身上}，{动作：轻轻转动手腕/抬手/走动两步}，{场景} 自然背景，{光}。
> 运镜：跟随手部或半身移动。
> 台词：{一句体感或使用场景}

注意：上身镜头里商品不要被手或衣服遮住主体；不要同时出现两个同类商品。

## S05 收尾 + 引导

> 画面：{主播} 回到镜头前，{商品} 在画面内可见，背景干净；微笑收住。
> 运镜：固定机位，轻微后拉。
> 台词：{一句总结} + {明确动作}

引导句要具体：

- "点下方小黄车，看今天的价。"
- "评论区打『要』，我发你尺寸表。"
- "橱窗里第二个，就是这条。"
- 不要写"感兴趣可以了解一下"——那不是引导。

## 英文版注意

英文台词按**词数**控制：一句 ≤ 20 词，句尾用句号收住。避免长从句，Gemini 会把从句压成机关枪。

## 反例（别这么写）

| 别写 | 为什么 |
| --- | --- |
| 一镜两句以上台词 | 10 秒装不下，必被截断 |
| "传承千年工艺，匠心独运" | 空话，模型会生成空洞表演 |
| "戴上它就能招财" | 功效承诺，平台违规 |
| 钩子就报商品名 | 悬念没了，划走率上升 |
| 收尾说"喜欢就买" | 没有动作指令 |
