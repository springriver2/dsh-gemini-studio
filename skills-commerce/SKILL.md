# 带货短视频

一条带货片只干四件事，顺序不能乱：

```
钩子（留住）→ 引出商品（为什么是它）→ 证据（近景 / 上身 / 使用）→ 收尾（总结 + 引导下单）
```

默认：**Gemini 原声说话**（人物开口、音画天然同步），一镜一句台词，每镜 10 秒。
只有用户明确要「旁白」时才改用 `tts_generate`（那时画面里不能有开口说话的人）。

## 能合并就合并

Gemini 一条视频就是 **10 秒**，而且要求用满。所以基本判断是：

> **一个 10 秒镜头讲得清的内容，就不要拆成两个。**

拆镜头是有代价的：多花一次额度、多一个接缝、多一次人物/商品不一致的风险。
反过来，**该拆的时候也别硬合**——换场景、换人、要一个干脆的转场、或者一个镜头塞不下时，就该拆。

常见时长大概长这样，**是参考不是硬性规定**，按实际内容定：

| 目标时长 | 大致镜数 | 每段怎么分 |
| --- | --- | --- |
| 20 秒 | 大约 2 镜 | 钩子+引出 / 证据+收尾 |
| **30 秒（最常见）** | **大约 3 镜** | 钩子+引出 / 证据 / 总结+引导 |
| 40 秒 | 大约 4 镜 | 钩子 / 引出+差异 / 细节 / 上身+收尾 |
| 50–60 秒 | 大约 5 镜 | 钩子 / 引出 / 细节 / 上身 / 收尾 |

**一镜可以装两小句**：只要加起来 ≤ 9 秒。比如第一镜先说钩子（4 秒）再说品类差异（5 秒），
比拆成两个 10 秒镜头更紧凑——观众不会觉得你在拖。

但别为了"少一个镜头"把三句话塞进 10 秒，那样必被截断，比多一个镜头更糟。

节奏参考：钩子永远占镜头的**前 3 秒**，收尾的引导动作留在镜头**最后 2 秒**。

## 30 秒 · 三镜标准结构

| 镜号 | 时间 | 画面 | 台词（≤9 秒，可以两小句） |
| --- | --- | --- | --- |
| S01 | 0–10s | 人对着镜头说话，手里已有商品但不给正脸；末段才把商品转到画面前 | 钩子（不报品名）+ 引出：品类 + 一个可验证的差异 |
| S02 | 10–20s | 一镜完成证据链：细节特写起手 → 手抬起戴上 / 上手使用 → 停在效果上 | 一句质感 + 一句体感（两小句） |
| S03 | 20–30s | 回到人，商品在画面里，背景干净，末两秒指向下方 | 一句总结 + 明确动作 |

**S02 是这类片子唯一的关键镜头**：它要同时给出"看得清"和"用得上"。
拍摄顺序固定成"特写 → 上身"，一镜内完成，不靠转场。

各品类的 S02 怎么做：

| 品类 | 一镜内的证据链 |
| --- | --- |
| 手串 / 首饰 | 孔道与包浆特写 → 手抬起戴到腕上 → 转腕看光 |
| 服饰 | 走线与面料垂坠 → 穿上身转身 → 抬手看版型 |
| 家居 | 边角与材质 → 放进真实房间 → 人物使用它 |
| 食品 | 切开/掰开的断面 → 入口咀嚼 → 拉丝或热气 |
| 美妆 | 质地在手背推开 → 上脸同光位 → 侧脸看光泽 |

## 镜头表（通用）

| 镜号 | 段落 | 画面 | 台词 |
| --- | --- | --- | --- |
| S01 | 钩子 + 引出 | 人对镜头，商品在手中但不抢镜 | 一句钩子（不报品名）+ 一句品类差异 |
| S02 | 证据 | 细节特写 → 上身/使用 → 停在效果 | 一句质感 + 一句体感 |
| S03 | 总结 + 引导 | 回到人，商品可见，末段指向下方 | 一句总结 + 一句动作指令 |

要 40 秒以上才把 S02 拆成"细节"和"上身"两条，别提前拆。

## 台词规矩（很重要）

1. **一镜一到两小句**，合计 ≤ 9 秒（中文约 30 字以内，英文约 20 词以内）；两小句之间要有明显停顿，别连成一串
2. 句子短、断句清楚，句尾收住——Gemini 会照念，长句会被压成机关枪或被截断
3. **不写功效承诺**（"治好""根治""百分百"），改说可观察的事实（"摸着凉""戴上不硌手"）
4. 数字只写能验证的（克重、尺寸、颗数），别编
5. 钩子那句**不要出现商品名**，把好奇留到同一镜的后半句或下一镜

## 出图与出镜

- **商品参考图必须先有**：一张正面、一张细节、一张场景（有条件再一张上手/上身）。用 `gemini_image` 生成或用户提供，登记进项目再引用。
- 人物只出现一次设定：同一个主播、同一套衣服、同一个场景，跨镜一致。第一镜的首帧即人物锚点，后续镜头接力或复用同一张设定图。
- 商品在画面里**不要变形**：近景镜头把商品放在画面中央、占 40% 以上，不要让人手遮住主体。

## 做完检查

- [ ] 没有为了凑时长把能合并的内容拆碎；也没有把三句话硬塞进一个 10 秒镜头
- [ ] 总时长与目标差 ≤ 2 秒
- [ ] 每镜剪入 = 整条用完（`retime_shots` 默认），**没有一句话被切断**
- [ ] 钩子在每片前 3 秒出现，且没有提前说出商品名
- [ ] S02 用一镜完成「细节 → 上身/使用 → 停在效果」，不靠转场硬凑
- [ ] 收尾有明确动作指令，不是"感兴趣可以看看"
- [ ] 字幕只覆盖台词，位置贴画面下方
- [ ] `media_verify` 通过（无白屏、无静音段）

## 在 DSH 里怎么跑

和 `video-production` 完全同一套工具，只是分镜按上面的结构写：

```
gemini_image          → 商品三视图、人物定妆、场景
studio.mjs ...        → 建项目、登记素材、生成分镜表
bridge-generate       → 逐镜出片（一镜 10 秒）
retime_shots          → 剪入对齐（默认整条用满）
short_compose         → 一条出片，自动配转场/字幕
media_verify          → 核验
```

具体镜头提示词模板见 [镜头模板](references/templates.md)，项目结构与命令见 `video-production` 技能。
